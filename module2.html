Digital Graphics

Raster vs. vector, the color models behind every screen and printer, file formats, and the Photoshop concepts that tie it together.

Raster vs. vector

Raster (bitmap)Vector
Made ofGrid of pixelsMath, paths, and curves
ScalingPixelated when enlarged — resolution-dependentScales infinitely, no quality loss — resolution-independent
Best forPhotographs, detailed imagesLogos, icons, type, flat art
Adobe toolPhotoshopIllustrator
FormatsJPEG, PNG, GIF, WEBPSVG, AI, EPS, PDF

Photos are always raster; logos and type are best as vectors. A poster is usually a raster photo background with a vector title/logo on top.

  • Pixels = inches × DPI
  • Screens run roughly 72–150 PPI
  • Prints run roughly 300 DPI
  • A3 = 3508 × 4961 px

Additive color occurs when combining all colors produces light (white). Subtractive is when combining all colors produces black (ink). The RGB gamut is more vivid than the CMYK gamut, so vivid screen colors dull in print.

DPI (dots per inch) measures physical printer resolution. PPI (pixels per inch) measures digital image and screen resolution.

Converting RGB to HEX

HEX is RGB written in base-16. Each channel becomes two hex digits (00–FF).

RGB (46, 84, 150) → 2E · 54 · 96
#2E5496

Worked example — computing one channel by hand

Take R = 46. Divide by 16 repeatedly and read the remainders from bottom to top:

46 ÷ 16 = 2, remainder 14 → 14 in hex is E
2 ÷ 16 = 0, remainder 2
Read remainders bottom→top: 2, then E
R = 2E

Reverse conversion works by splitting the hex string into pairs and converting each pair to decimal — e.g. #1F3864 → 31, 56, 100. Black is #000000, white is #FFFFFF.

Decision guide

  • Photograph? → JPEG or WEBP
  • Transparency / crisp text? → PNG or WEBP
  • Logo/icon/type that must scale? → SVG
  • Short animation? → GIF or WEBP
  • Modern web, size matters? → WEBP

Kinds of layers

  • Pixels (raster) — ordinary image content
  • Type — live, re-editable text
  • Shape — vector rectangles, ellipses, custom shapes
  • Adjustment — color/tonal change applied to layers beneath it
  • Smart object — protects original data through repeated transforms

Non-destructive editing

Making changes that never permanently alter the original pixels, so they stay reversible.

  • Eraser → Layer mask
  • Image adjustments → Adjustment layer
  • Scaling → Smart object
  • Only ever copy → Duplicate first

Layer masks are alpha channels: white reveals, black conceals, grey is partial.

Exporting

PSD is your layered, editable master file — keep it always. Export As flattens the image to JPEG/PNG/WEBP for delivery. A JPEG cannot be unflattened.
